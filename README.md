# bms_FC
Farook College Group 4 project (2021 - 2024)

------------------------------------------------------------
Bus Management System (Flutter)
------------------------------------------------------------
A mobile-based Bus Management System developed using Flutter, designed to streamline bus tracking, scheduling, and management for students and administrators. This application provides real-time access to bus information, improving efficiency and user convenience.

-------------------------------------------------------------
🚀 Features:-
-------------------------------------------------------------
📍 Real-time Bus Tracking
Track the live location of buses for better planning.

🗓️ Bus Schedule Management
View routes, timings, and assigned buses.

👤 User Authentication
Secure login system for students and admins.

🔔 Notifications & Alerts
Get updates about delays, route changes, or important announcements.

📊 Admin Panel
Manage buses, routes, and users efficiently.

----------------------------------------------------------------
🛠️ Tech Stack
----------------------------------------------------------------
Frontend: Flutter (Dart)
Backend: Firebase 
Database: Firestore
Tools: Android Studio / VS Code / Git
